# HQ

A scannable dashboard for Iftisam’s bot team at `/builds/hq/`. Plain HTML and CSS — no build step. One card each for Client Finder, Market Watch, and Watch Later.

Each card shows, in order: title, status, the given numbers, what’s waiting on Iftisam, and the required links.
